Privacy by design

Radical privacy through database security

Protection is built into the database layer, not just the application code.

Row-Level Security

Each query runs with a transaction-scoped user identity. PostgreSQL itself filters out every row that is not yours, even if a query forgets its WHERE clause.

Encrypted journal

Journal reflections are encrypted with Fernet (authenticated AES) before they are written. Only ciphertext reaches the database tables.

Granular consent

Choose what MindGuard may do with your data: analytics, storage, and policy acceptance are all individual switches you can change at any time.

Admin-blind by design

Administrators manage accounts and read security audit logs and aggregate health numbers. The admin screens contain no mood or journal data.
