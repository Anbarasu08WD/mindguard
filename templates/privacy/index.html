How Relational Security Guarantees Your Privacy

MindGuard was engineered specifically to demonstrate how relational databases enforce security mechanisms.

Row-Level Security

Policies on mood_records, journal_entries, and wellness_reports enforce that PostgreSQL only yields records matching app.current_user_id.

Fernet Cryptography

Reflections are sealed with authenticated symmetric tokens. If the database file were ever dumped, journal contents remain encrypted.

Principle of Least Privilege

The Flask application connects as mindguard_app, which lacks SUPERUSER and BYPASSRLS privileges, strictly bound to security rules.

Delete Account & Permanent Purge

Permanently deletes your user account, mood records, encrypted journal reflections, consent records, and active sessions. This action is irreversible.
